### D5: 架构↔API 一致性（6/10 → 10/10）

**问题列表（修复前共 5 处矛盾，触发 V4）：**

| 级别 | 问题 | 修复状态 |
|------|------|---------|
| P0 | 角色名：架构 §4.2 使用 "GUARDIAN"，API §1.4 使用 "USER" | 已修复（→ USER） |
| P0 | 成功码：架构 §4.4 使用 `code: 0`，API §1.2 和共享内核使用 `code: 200` | 已修复（→ 200） |
| P0 | PageData 字段：架构使用 `list`，API 和共享内核使用 `records` | 已修复（→ records） |
| P0 | PageData 缺少 `pages` 字段：架构未包含，API 和共享内核有 | 已修复（+ pages） |
| P0 | 登录方式：架构 §5.1 使用短信验证码，API §2.2 使用密码 | 已修复（→ 密码） |
| P0 | Token 过期错误码：架构使用 `40101`，API 和共享内核使用 `1001` | 已修复（→ 1001） |

**修复内容**：

- §4.2 路由守卫：`GUARDIAN` → `USER`
- §4.4 响应格式：`code: 0` → `code: 200`
- §4.4 分页响应：`list` → `records`，新增 `pages: 5`
- §4.4 Token 刷新：`40101` → `1001`
- §4.4 请求拦截：`code === 0` → `code === 200`
- §5.1 认证流程：`login(phone, smsCode)` → `login(phone, password)`，短信验证改为密码验证
- §5.1 JWT payload：`roles: ["GUARDIAN"]` → `roles: ["USER"]`
