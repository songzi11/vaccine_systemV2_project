# 前后端联调操作手册

## 环境准备

### 1. 启动后端
```bash
cd vaccine_systemV2
# 确保 MySQL 和 Redis 已启动
# 确保 application.yml 中数据库连接配置正确
mvn spring-boot:run -pl vaccine-start
```

### 2. 初始化测试数据
```sql
-- 在 MySQL 中依次执行：
source vaccine_db_init.sql
source integration_test_data.sql
```

**重要：** 执行 `integration_test_data.sql` 前，需要先生成 `123456` 的 BCrypt hash 并替换 SQL 中的占位 hash。

### 3. 验证后端启动
浏览器访问 `http://localhost:8080/doc.html`（Knife4j 文档）

### 4. 启动前端
在 HBuilderX 中打开 `vaccine_systemV2app`，运行到 H5 或模拟器

## 阶段 2：核心业务流程（12 个 API）

### 2.1 创建预约
1. 家长账号 `13800000001` 登录
2. 进入创建预约页面
3. 选择儿童"小明"
4. 选择疫苗（如：乙型肝炎疫苗，vaccineId=1）
5. 选择日期（未来日期）和时段（AM/PM）
6. 提交 → 验证预约成功，状态为"已预约"

### 2.2 查看预约
- [ ] 预约列表显示新创建的预约
- [ ] 点击查看详情，验证所有字段正确

### 2.3 签到（签到医生 13900000006）
- [ ] 切换账号到签到医生
- [ ] 在签到队列中看到预约记录
- [ ] 执行签到 → 验证状态变为"已签到"

### 2.4 预检（预检医生 13900000001）
- [ ] 切换账号到预检医生
- [ ] 在预检队列中看到签到记录
- [ ] 提交预检评估（体温 36.5，结果 PASS）
- [ ] 验证状态变为"预检通过"

### 2.5 登记（登记医生 13900000002）
- [ ] 切换账号到登记医生
- [ ] 在登记队列中看到预检通过记录
- [ ] 执行登记 → 验证状态变为"已登记"

### 2.6 接种（接种医生 13900000003）
- [ ] 切换账号到接种医生
- [ ] 在接种队列中看到登记记录
- [ ] 获取 FEFO 推荐批次
- [ ] 选择注射部位（如：LEFT_UPPER_ARM）
- [ ] 执行接种 → 验证接种记录生成

### 2.7 留观（留观医生 13900000004）
- [ ] 切换账号到留观医生
- [ ] 在留观队列中看到接种完成记录
- [ ] 开始留观
- [ ] 结束留观（时长 ≥ 1 分钟）
- [ ] 验证状态变为"已完成"

### 2.8 查看接种记录
- [ ] 切回家长账号
- [ ] 查看接种记录列表 → 应包含刚完成的记录
- [ ] 查看儿童接种记录

### 2.9 取消预约
- [ ] 创建新预约
- [ ] 取消预约（填写原因）
- [ ] 验证状态变为"已取消"

### 2.10 权限验证
- [ ] 家长无法访问医生端页面
- [ ] 预检医生无法执行接种操作

## 阶段 3：留观 + 库存管理（15 个 API）

### 3.1 不良反应流程
1. 完成接种 → 开始留观
2. 上报不良反应（选择严重程度 MILD/MODERATE/SEVERE）
3. 查看不良反应记录
4. 处理不良反应（填写处理结果）
5. 结束留观

### 3.2 库存管理（库管医生 13900000005）
- [ ] 查看库存总览 → 验证 5 个批次数据正确
- [ ] 查看批次列表
- [ ] 创建新批次（入库）
- [ ] 库存调拨（从仓库到接种点）
- [ ] 批次报损
- [ ] 查看库存预警

### 3.3 数据一致性
- [ ] 入库后库存总览数量增加
- [ ] 调拨后源位置减少、目标位置增加
- [ ] 报损后数量减少
