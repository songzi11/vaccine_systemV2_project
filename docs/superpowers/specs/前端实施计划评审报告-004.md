**具体位置：**

| 文件 | 错误导入行 | 应修改为 |
|------|-----------|---------|
| 家长端 guide.vue | `import { ref, computed, onShow, onHide, onUnload } from 'vue'` | `import { ref, computed } from 'vue'` + 注释说明 |
| 医生端 calling/index.vue | `import { ref, onShow, onHide } from 'vue'` | `import { ref } from 'vue'` + 注释说明 |
| 医生端 observe-detail.vue | `import { ref, computed, onShow, onHide, onUnload } from 'vue'` | `import { ref, computed } from 'vue'` + 注释说明 |
| 管理员端 window/list.vue | `import { ref, computed, onShow } from 'vue'` | `import { ref, computed } from 'vue'` + 注释说明 |
| 管理员端 vaccination/stats.vue | `import { ref, onShow } from 'vue'` | `import { ref } from 'vue'` + 注释说明 |

**说明：** 此问题为修复过程中引入的新问题。医生端已有的 signin-confirm.vue 和 precheck-assess.vue 中的 `onLoad` 问题已通过添加注释正确处理，但新增代码块使用了不同的（错误的）处理方式——将 uni-app 生命周期从 vue 导入。**修复方式：** 从 import 语句中移除 `onShow`/`onHide`/`onUnload`，并添加 `// uni-app 全局生命周期（onShow/onHide/onUnload）无需从 Vue 导入` 注释。

**注意：** 医生端计划中已有的多个代码块（如个人中心 index.vue、签到队列 signin.vue、预检队列 precheck.vue 等）也存在相同的错误导入模式，但这些问题存在于修复前，本次重新评审不追溯历史问题。
